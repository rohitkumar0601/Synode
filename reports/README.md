# Analysis & Benchmark Reports Directory

This directory contains the synthesized evaluation artifacts, statistical ranking plots, ε-tradeoff curves, cost tables, and summary markdown generated by `scripts/make_report.sh` (powered by the `packages/analysis` pipeline).

## Contents

- `results.md`: Complete human-readable summary of the benchmark run, including RQ1 ranks, RQ2 ε-curves, Pareto-front shifts, and resource consumption numbers.
- `tables/`:
  - `results.parquet` / `results.csv`: Tidy collection table containing per-run, per-dataset, per-generator, and per-seed results.
  - `rq1_core_ranks.csv` / `rq1_core_ranks.md` / `rq1_core_ranks.tex`: Ranking tables across core benchmark datasets.
  - `rq1_meta_ranks.csv` / `rq1_meta_ranks.md` / `rq1_meta_ranks.tex`: Ranking tables across OpenML-CC18 benchmark datasets.
  - `rq2_pareto_shifts.csv` / `rq2_pareto_shifts.md`: Pareto-frontier shift tables with and without DP candidates.
  - `cost_summary.csv` / `cost_summary.md` / `cost_summary.tex`: Training time, sampling time, and peak memory (RSS) per generator.
- `figures/`:
  - `rq1_*_cd.png` / `rq1_*_cd.pdf`: Critical Difference (CD) diagrams generated via `autorank` (Friedman + Nemenyi tests).
  - `rq2_*_curves.png` / `rq2_*_curves.pdf`: Quality, utility, and privacy metrics as a function of differential privacy budget ε (0.1, 1.0, 10.0).
  - `rq2_*_pareto.png` / `rq2_*_pareto.pdf`: 2D and 3D Pareto frontier visualizations.
  - `cost_time_*.png` / `cost_memory_*.png`: Execution time and memory footprint comparisons.

## Regeneration

To regenerate all reports and figures from local and integrated artifact stores:

```bash
bash scripts/make_report.sh
```

Or pass explicit stores:

```bash
bash scripts/make_report.sh --store outputs/store --store outputs/store_integrated --out reports
```
